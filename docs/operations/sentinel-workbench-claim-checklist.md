# Sentinel Workbench claim checklist

Public result language requires **all** of:

- eligible independent corpus with frozen truth
- complete B0–B3 controls
- valid `k=3`
- matched B3−B2 re-score
- calibration and power lineage
- digest-bound independent reproduction record

## Do not claim effectiveness from

| Evidence | Why it is insufficient |
|----------|------------------------|
| Engine preflight `ready` | Image pin + frozen policy only; not a scan, not a corpus |
| CMC inventory / transport smoke | Case-study workflow, not recall/precision/AI effect |
| Missing or unfrozen truth | No adjudication baseline |
| instrument-invalid / not-measured / underpowered/descriptive states | Explicit non-claims |
| Fixture readiness refusal | Containment demo, not analysis |
